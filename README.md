# Speech AI Lab

Aplicação Python para experimentar dois fluxos de inteligência artificial generativa:

- Speech-to-Text (STT)
- Text-to-Speech (TTS)
- Speech -> Text -> Speech

## Tecnologias

- Python
- OpenAI Python SDK
- OpenAI Audio API
- python-dotenv
